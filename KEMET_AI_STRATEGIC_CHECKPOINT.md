# KEMET AI — Strategic Checkpoint

## Vision
KEMET AI BOS — AI Business Operating System.
Goal: build a globally competitive business platform, with the explicit ambition to become a leading platform in Egypt and the Arab world and expand globally.

Slogan: Don't use another AI tool. Run your business with Kemet.

## Product Model
Kemet is one integrated platform, not a collection of unrelated tools or bots.
Core loop:
Understand -> Decide -> Review -> Approve -> Execute -> Measure -> Learn.

## User Experience
- Arabic + English from the start.
- Arabic uses RTL; English uses LTR.
- Localization covers UI, messages, AI responses, notifications, billing and core journeys.
- Responsive web is the first universal client for phone, tablet, laptop and desktop.
- Native mobile app is planned later, using the same Core and APIs.

## Omnichannel
Planned access channels:
- Web / Unified Command Center
- WhatsApp Bot
- Telegram Bot
- Native mobile app later

WhatsApp and Telegram must connect to the same Kemet Core. They are channel adapters, not separate business products. Identity, tenant isolation, permissions, intelligence, governance and execution rules are shared.

## Safety / Governance
Human approval remains mandatory for consequential actions.
No channel may bypass the Central Execution boundary.
Read-only intelligence can be delivered when authorized; external side effects require the existing approval flow.

## Strategic Rule
Do not build many weak mini-projects.
Every new capability must pass:
1. Global value
2. Revenue or cost impact
3. Real intelligence gain
4. Competitive moat
5. Integration with Kemet

Decision labels: BUILD / INTEGRATE / WATCH / REJECT.

## Resume Instruction
When work resumes, continue from the current implementation milestone instead of restarting old audits.
First finish Subscription & Billing Integrity, prove it with one comprehensive test, then advance to payment infrastructure.
Keep Arabic/English and Web/WhatsApp/Telegram architecture as platform-level requirements.
