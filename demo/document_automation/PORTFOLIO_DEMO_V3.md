# Kemet Document Intelligence — Commercial V3 Demo

**Synthetic portfolio demo — no customer data.**

## The promise
Turn messy business documents into clean, validated, traceable data.

## What the client experiences
1. Upload source documents.
2. Kemet identifies the document type and extracts structured fields.
3. Every important value keeps source evidence where available.
4. Validation checks arithmetic, required fields, confidence and duplicates.
5. Exceptions are isolated for human review.
6. The final package contains professional Excel, CSV and machine-readable evidence.

## Pipeline
INGEST → CLASSIFY → EXTRACT → NORMALIZE → VALIDATE → CONFIDENCE → DUPLICATE CHECK → EXCEPTION CENTER → QUALITY SCORECARD → DELIVERY

## V3 proof points
- Field-level heuristic confidence.
- Source-line grounding.
- SHA-256 input evidence.
- Deterministic duplicate detection.
- Financial consistency checks.
- Human review remains authoritative.
- Quality scorecard separates extraction confidence from validation outcome.
- Customer-specific deterministic rules can be attached to a delivery.
- No 100% accuracy claim.
